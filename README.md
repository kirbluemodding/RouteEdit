# RouteEdit
###### An editor for NSMBW's RouteInfo.arc derived from NSMB2's routeInfo file editor

This is a fork of the NSMB2 RouteEdit, modified for the usage of the NSMBW `RouteInfo.arc`.
The UI is adjusted to fit the NSMBW system, and anything incompatible with NSMBW 
was removed.

Credits go to Explos for the original program and me
for modifying it.

See https://horizon.miraheze.org/wiki/Editing_the_Original_Maps
for a thorough documentation of the NSMBW retail world map system.

### Requirements
* Python3
* PyQt6 `pip install pyqt6`
### Usage
* Run RouteEdit.py
* Open a RouteInfo.arc File
* Use the `Node Unlocks` Tab to edit the available nodes for each world
* Use the `Path Settings` Tab to edit the sound and action used for each path
